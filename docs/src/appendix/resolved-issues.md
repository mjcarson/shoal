# Resolved Issues

Defects that have been fixed, kept because the reasoning behind a fix is worth more than
the fix itself. Each page states what went wrong, why, what shape the fix took, what was
rejected on the way, and — the part that matters when changing this code later — the
invariants the fix depends on.

Item numbers are shared with [Known Issues](known-issues.md) and never reused, so a number
appears on exactly one of the two pages. The exceptions are items 16, 20, 24 and 54, which were
only partly fixed and appear on both: the fixed half here, the open remainder there. Items 9 and 51
were each one of those exceptions until their second half was fixed, and now appear here alone.

Numbers are also grouped when one change closed several items that turned out to share a cause —
7 and 10, 26 and 39, 56 and 61, 67 and 68, and 11, 12 and 37 each have one page rather than
several.

## How a fix gets written down

Not every bug earns a page. These do because each one had a wrong mental model behind it, and
a page that only said "fixed in commit X" would let the same mistake back in. The sections are
always the same:

**Symptom** what was observable. **Cause** the code as it was. **Evidence** how it was
established — read, or reproduced, and the difference is stated. **The fix** and **Alternatives
rejected**, together, because a fix is only understandable next to what it is not.
**Invariants to uphold**, which is the section to read before changing the code it describes.
**Tests**, naming what fails if the fix is reverted.
| 79 | [A capture of one layer decided what every page drew](resolved/micro-only-capture-current.md) | `render` chose one capture for all eleven pages — the newest with a micro layer — so a `--layer micro` capture emptied the seven macro pages, which then said nothing had ever measured a mixture while eleven macro captures sat in the same directory. Reproduced against the committed corpus with `render --current inline-probe`, which takes `grid.md` from 59,287 bytes to 3,459. The default is now resolved **per layer** and screened on `LayerRecord::complete`, so each page names the newest *whole* capture of the layer it draws and a filtered capture never outranks a full one. `--current` stays an instruction. The converse — [item 77](known-issues.md), a macro-only capture having no way to say it re-measured rows a page is drawing stale — is **not** closed by this |
